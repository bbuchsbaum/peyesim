# peyesim documentation site

A static [Fumadocs](https://fumadocs.dev) (Next.js) site, published to
GitHub Pages by `.github/workflows/docs.yml`.

- `source/` holds the authored pages: Markdown with Python cells, plus
  `meta.json` files that order the sidebar. Edit these.
- `content/` is generated by `python tools/build_docs.py`, which executes every
  Python cell (output and figures are written into the page) and builds the API
  reference from the package docstrings. Do not edit it; it is not committed.
- `app/`, `components/` and `lib/` are the site itself.

```bash
pip install -e ".[docs,viz]"   # from the repository root
make docs-preview              # lint, generate content, run the dev server
make docs                      # static export in docs/out
```

Cell options go on leading `#|` lines: `#| eval: false` shows code without
running it, `#| echo: false` hides the code, `#| output: false` hides the
results. The API reference is grouped by `REFERENCE_SECTIONS` in
`tools/build_docs.py`; `tests/test_docs_reference.py` checks that every public
name appears there once.
